# Ameer Suhail - Senior Graphic Designer & Brand Specialist

Welcome to the official digital portfolio of **Ameer Suhail**, Senior Graphic Designer and Brand Specialist based in Umm Al Quwain, UAE (UAQ Next / Tourism Department).

## Features
- **Luxury Swiss Aesthetic:** Obsidian Slate & Champagne Gold dark theme.
- **Universal Case Study Engine:** Embedded PDF presentations and high-resolution vertical photo gallery slides.
- **Dynamic Projects Catalog:** Interactive popup modal with real-time category filtering.
- **Private Studio CMS (dmin.html):** In-browser management suite with 1-click JSON backup and GitHub auto-deploy integration.
- **Ultra-Fast & Responsive:** Zero external framework dependencies, pure HTML5, CSS3, and modern ES6 JavaScript.

## Deploying to Netlify
1. Log in to [Netlify](https://app.netlify.com).
2. Drag and drop the \Ameer_Portfolio.zip\ or the website folder directly onto the Netlify deploy zone.
3. Your website is instantly live with free SSL.

## Live Admin CMS
Access the CMS at \/admin.html\ using your master password.
